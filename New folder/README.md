# TURBO KIDS v9 — by GEMY

## النشر والتحديث التلقائي
1. ارفع محتوى هذا المجلد كما هو (بنفس المجلدات) إلى ريبو GitHub واربطه بمشروع Vercel (Git Integration).
2. كل `push` على `main` ينشر نسخة جديدة تلقائيًا. `vercel.json` يضع رقم الـ commit داخل `sw.js` فيتحدّث عند اللاعبين تلقائيًا.
3. يلزم متغيرات Upstash/KV الموجودة أصلًا في Vercel، ولا يلزم أي باك اند آخر.
4. لو غيّرت إعدادات Build في لوحة Vercel (Framework = Other)، تأكد أن Output Directory هو `.`.

## بدون إنترنت
`sw.js` يجرّب الشبكة أولًا (4 ثوانٍ) ثم يرجع لآخر نسخة محمّلة. ملفات Three.js والخطوط تُخزَّن بعد أول فتح بالإنترنت. التقدم محلي أولًا ويُزامَن عند عودة الاتصال.

## الحسابات
`api/account.js` (اسم مستخدم + كلمة مرور + كود استرجاع) على نفس Redis. كلمات المرور مشفّرة بـ scrypt، والجلسات توكن عشوائي، مع حد للمحاولات. الضيف يستمر بكود الحفظ القديم (`api/save.js`, `api/load.js`).

## الباندا
`js/pet.js` + `css/pet.css`: شبع يتناقص ببطء (لا يقل عن 15%)، خيزران من الإجابات الصحيحة، 3 إكسسوارات، 3 مراحل حسب النجوم. الحالة في `S.pet` وتتزامن مع الحساب.

## تحسينات تجربة الاستخدام (`js/polish.js`, `css/polish.css`)
- جولة تعريفية مرة واحدة مع الباندا، ومهمة يومية (10 إجابات صحيحة = 25 عملة).
- وضع تدريب بدون فقدان قلوب (الإعدادات)، وبعد خطأين متتاليين يُعاد الصوت مع تشجيع.
- الباندا ترافق الطفل في السباق وتفرح عند الإجابة الصحيحة.
- شارة "أوفلاين"، وتحميل أصوات الحروف في الخلفية مرة واحدة لتعمل بدون نت.
- انتقال ناعم بين الشاشات واحترام `prefers-reduced-motion`.
